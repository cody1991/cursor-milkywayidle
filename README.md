# Galaxy Cow Idle - 银河奶牛农场

一个基于 WebSocket 的实时银河奶牛农场放置游戏，玩家通过主动选择生产活动来获得资源和提升等级。

## 🌟 游戏特色

### 🎯 活动式生产系统

- **主动生产**: 玩家需要主动选择资源模块和单位进行生产活动
- **等级限制**: 每个单位都有等级要求，需要提升模块等级才能使用
- **时间管理**: 每次活动都有特定的时间，玩家可以设置活动次数
- **经验系统**: 通过生产活动获得经验值，提升模块等级

### 📈 等级系统

- 每个模块都有独立的等级和经验系统
- 通过生产活动获得经验值
- 等级提升后可以解锁更高级的单位
- 等级名称：新手 → 学徒 → 专家 → 大师 → 传奇

### 🌟 实时功能

- **WebSocket 连接**: 实时数据同步
- **在线聊天**: 与其他玩家交流
- **实时排行榜**: 查看玩家排名
- **成就系统**: 解锁各种成就
- **自动保存**: 游戏进度自动保存

## 🎮 游戏玩法

1. **选择模块**: 点击想要使用的资源模块
2. **选择单位**: 在模块中选择可用的生产单位（需要达到等级要求）
3. **设置活动**: 选择要进行的活动次数
4. **开始生产**: 点击"开始活动"按钮
5. **等待完成**: 活动会在后台进行，完成后自动获得资源和经验

## 🌌 银河主题

虽然游戏以奶牛农场为核心，但背景设定在浩瀚的银河系中：
